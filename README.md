# E-commerce--EDA-Analysis-project-2-
Week 2 project from Decodelabs internship

📊 E-commerce EDA Analysis

🧠 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an e-commerce dataset using Microsoft Excel. The goal is to uncover business insights, identify sales trends, analyze customer behavior, and provide actionable recommendations.

---

📁 Dataset Features

The dataset contains the following fields:

- Date
- CustomerID
- Product Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- Tracking Number
- ItemsInCart
- CouponCode
- ReferralSource
- TotalPrice

---

🛠️ Data Cleaning

The following preprocessing steps were performed:

- Checked for missing values.
- Replaced missing CouponCode values with "Unknown".
- Verified data consistency across columns.
- Prepared the dataset for Pivot Table analysis.

---

📊 Key Metrics

- Total Orders: 1200
- Total Revenue: 1,264,761.96
- Average Order Value: 1053.97

---

🔍 Key Findings

Customer Analysis

- Customer spending is relatively balanced across users.
- No significant dependency on a small group of customers.

Order Status Analysis

- Order statuses are distributed across different order lifecycle stages.
- The dataset provides balanced operational scenarios for analysis.

Payment Methods

- Payment preferences are evenly distributed across available methods.
- No single payment method dominates customer transactions.

Coupon Analysis

- Coupon usage is balanced across promotional campaigns.
- Missing coupon values were identified and handled during data cleaning.

Sales Trend Analysis

- Sales consistently peak around May–June across multiple years.
- Revenue fluctuates throughout the year, indicating seasonal demand patterns.
- June 2024 recorded the highest monthly revenue in the dataset.

---

💡 Recommendations

- Focus marketing campaigns during peak months (May–June).
- Introduce promotions during low-performing periods.
- Implement customer retention strategies to improve revenue stability.
- Continue supporting multiple payment methods.
- Improve data collection processes to reduce missing promotional information.

---

📈 Tools Used

- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Exploratory Data Analysis (EDA)

---

🧠 Conclusion

The analysis revealed seasonal sales patterns, diversified payment preferences, and balanced customer purchasing behavior. The findings highlight opportunities to improve revenue stability and optimize marketing efforts throughout the year.
